# ココペリ Meta広告「準備中」問題 — 修正手順書

**作成日:** 2026-04-07
**対象キャンペーン:** ココペリ 売上CV — ペット用シリカウォーター
**問題:** キャンペーンが「準備中」のまま配信されない

---

## 1. 現在の問題点

キャンペーン目的が「売上（コンバージョン）」に設定されているが、Meta Pixelが**非アクティブ**状態のため、Metaが配信を開始できない。

コンバージョン目的のキャンペーンでは、Pixelが最低1件の最適化イベント（購入イベント）を受信・検証済みである必要がある。ココペリPixelはまだ1件も購入イベントを受信していないため、Metaが「準備中」で配信をブロックしている。

---

## 2. 対策A: キャンペーン目的を「トラフィック」に一時変更する

トラフィック目的はPixel検証が不要なため、すぐに配信開始できる。

### 手順（Meta Ads Manager）

1. **Ads Managerを開く**
   - https://adsmanager.facebook.com/ にアクセス
   - ココペリのビジネスアカウントでログインしていることを確認

2. **対象キャンペーンを選択**
   - キャンペーン一覧から「ココペリ 売上CV — ペット用シリカウォーター」を見つける
   - ステータスが「準備中」になっていることを確認

3. **既存キャンペーンをオフにする**
   - 既存キャンペーンのトグルをオフにする（目的は後から変更できないため、新規作成が必要）

4. **新規キャンペーンを作成**
   - 「+作成」ボタンをクリック
   - キャンペーン目的: **トラフィック** を選択
   - 「次へ」をクリック

5. **キャンペーン設定**
   - キャンペーン名: `ココペリ トラフィック — ペット用シリカウォーター`
   - 日予算: ¥1,000
   - 「次へ」をクリック

6. **広告セット設定**
   - コンバージョンの場所: **ウェブサイト**
   - 最適化対象: **リンクのクリック**（またはランディングページビュー）
   - ターゲティング: 既存キャンペーンと同じ設定を再現
     - 地域: 日本
     - 年齢・性別: ペット飼い主層に合わせて設定
   - 配置: Advantage+（自動配置）推奨
   - 「次へ」をクリック

7. **広告クリエイティブ設定**
   - 既存の広告と同じクリエイティブ（画像・テキスト・URL）を設定
   - リンク先URL: `https://kokopelli.kamuturu.jp`
   - 「公開」をクリック

8. **配信確認**
   - 数分〜数時間で「審査中」→「配信中」に変わることを確認
   - 旧キャンペーン（売上CV）はオフのままにしておく

---

## 3. Pixel検証完了後に売上（CV）目的に戻す手順

Pixelが購入イベントを受信し、イベントマネージャで「アクティブ」になったら実施する。

### 確認方法

1. https://business.facebook.com/events_manager/ にアクセス
2. 「ココペリ Pixel」を選択
3. 「購入（Purchase）」イベントが表示され、最終受信時刻が表示されていれば検証完了

### 切り替え手順

1. Ads Managerで「+作成」→ 目的「売上」を選択
2. キャンペーン名: `ココペリ 売上CV — ペット用シリカウォーター v2`
3. 日予算: ¥1,000
4. 広告セット:
   - コンバージョンイベント: **購入（Purchase）**
   - Pixel: ココペリ Pixel を選択
   - ターゲティング: トラフィックキャンペーンと同じ設定
5. 広告クリエイティブ: トラフィックキャンペーンと同じ
6. 公開後、配信開始を確認
7. トラフィックキャンペーンをオフにする

---

## 4. 代替案: イベントマネージャでテストイベントを送信して検証を通す

Pixelを先にアクティブにできれば、売上（CV）目的のまま配信可能になる。

### 方法A: テストイベントツールを使う

1. **イベントマネージャにアクセス**
   - https://business.facebook.com/events_manager/ を開く
   - 「ココペリ Pixel」を選択

2. **テストイベントタブを開く**
   - 上部タブから「テストイベント」をクリック

3. **ブラウザイベントをテスト**
   - 「ブラウザイベントをテスト」セクションに、ECサイトのURLを入力:
     ```
     https://kokopelli.kamuturu.jp
     ```
   - 「ウェブサイトを開く」をクリック
   - 別タブでサイトが開くので、実際に購入フロー（カート追加→チェックアウト→決済）を模擬的に実行する
   - テストイベントタブに戻り、イベントが受信されたか確認

### 方法B: Meta Pixel Helperで手動検証

1. Chrome拡張「Meta Pixel Helper」をインストール
   - https://chrome.google.com/webstore/detail/meta-pixel-helper/fdgfkebogiimcoedlicjlajpkdmockpc
2. ECサイト（ https://kokopelli.kamuturu.jp ）にアクセス
3. Pixel Helperアイコンをクリックし、Pixelが発火しているか確認
4. **PageViewすら発火していない場合** → サイト側のPixelコード実装に問題がある

### 方法C: コンバージョンAPIでサーバーサイドイベントを送信

Pixelのブラウザ側実装に問題がある場合、サーバーサイドから直接イベントを送信できる。

```bash
curl -X POST \
  "https://graph.facebook.com/v19.0/PIXEL_ID/events" \
  -H "Content-Type: application/json" \
  -d '{
    "data": [{
      "event_name": "Purchase",
      "event_time": '$(date +%s)',
      "action_source": "website",
      "event_source_url": "https://kokopelli.kamuturu.jp",
      "user_data": {
        "client_ip_address": "0.0.0.0",
        "client_user_agent": "Mozilla/5.0"
      },
      "custom_data": {
        "currency": "JPY",
        "value": 5480
      }
    }],
    "test_event_code": "TEST_EVENT_CODE_FROM_EVENTS_MANAGER",
    "access_token": "YOUR_ACCESS_TOKEN"
  }'
```

- `PIXEL_ID`: ココペリPixelのID（イベントマネージャで確認）
- `TEST_EVENT_CODE`: テストイベントタブに表示されるコード
- `access_token`: ビジネス設定 → システムユーザー → アクセストークンで発行

**注意:** `test_event_code`を付けている間はテストイベントとして扱われる。本番運用時は`test_event_code`を外すこと。

## 推奨アクション（優先順）

| 優先度 | アクション | 所要時間 | 効果 |
|--------|-----------|----------|------|
| 1 | トラフィック目的で新規キャンペーン作成（対策A） | 15分 | 即日配信開始 |
| 2 | テストイベントでPixel検証（代替案A/B） | 30分 | Pixel有効化 |
| 3 | Pixel検証完了後に売上CV目的に切替（対策B） | 15分 | CV最適化開始 |

**まずは対策Aで配信を開始し、並行してPixel検証を進めるのが最速の戦略。**
