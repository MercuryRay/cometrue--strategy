# ペットにケイ素（シリカ）を与えるメリットと選び方

最近、ペットの健康管理においてケイ素（シリカ）が注目されています。人間用のケイ素サプリは以前から販売されていますが、ペット用のケイ素サプリも増えてきました。

今回は、ペットにケイ素を与えるメリットと、選び方のポイントをまとめました。

## ケイ素（シリカ）とは

ケイ素は地球上で酸素の次に多い元素で、人間やペットの体内にも微量に存在するミネラルです。

骨、関節、皮膚、被毛、爪など、体の様々な組織に含まれており、これらの組織の健康維持に関わっていると考えられています。

## ペットにケイ素を与えるメリット

ケイ素は年齢とともに体内量が減少します。特にシニア期のペットでは、食事からの摂取だけでは不足しがちです。

ケイ素サプリを与えることで、日々の栄養補給として活用できます。

## ペット用ケイ素サプリの選び方

### 1. 水溶性であること

ケイ素には「水溶性」と「不溶性」があります。体内に吸収されやすいのは水溶性ケイ素です。サプリを選ぶ際は「水溶性ケイ素」と明記されているものを選びましょう。

### 2. 濃度を確認する

水溶性ケイ素サプリの濃度は製品によって異なります。ケイ素濃度が高いほど、少量で効率的に摂取できます。

### 3. 原材料がシンプルであること

余計な添加物が入っていないものが安心です。ペット用サプリは「原材料が少ないほど良い」と考えてよいでしょう。

### 4. 動物病院での使用実績

獣医師や動物病院で使われている製品であれば、安全性についてある程度の信頼がおけます。

## ココペリの特徴

ペット用水溶性ケイ素サプリ「ココペリ」は、以下の特徴があります。

- 水溶性ケイ素濃度 10,000mg/L（高濃度）
- 原材料は水とケイ素のみ（無添加）
- 動物病院で10年間使用されてきた実績
- 学会での症例報告あり
- 犬にも猫にも使用可能
